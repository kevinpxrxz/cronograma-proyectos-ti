Criterios de aceptación

Una frase por criterio que diga qué se espera de la funcionalidad. Ej.: «Como usuario, debo poder acceder al portal con mi usuario y contraseña.»

Revisión con IA (Claude)

La IA lee cada historia (descripción, criterios y mockups) y te indica las ambigüedades: términos vagos, criterios que no se pueden probar, información que falta, contradicciones, casos no cubiertos y diferencias con los mockups. También compara las historias entre sí, propone criterios faltantes y preguntas para el negocio.

Créala en console.anthropic.com → API keys. Se usa el modelo Claude Opus 5.5; cada revisión tiene un costo según el largo de las historias (normalmente unos centavos de dólar). Te recomendamos fijar un límite de gasto en la consola. La clave solo se envía a Anthropic.

¿No tienes clave? Pulsa Copiar para claude.ai: se copian las instrucciones y tus historias pendientes para pegarlas en una conversación de claude.ai. Las imágenes adjúntalas tú en esa conversación.

Conexión con Azure DevOps

Cada historia se crea como un elemento de trabajo en el tablero de tu proyecto, con sus mockups como adjuntos. Si cambias una historia y la vuelves a subir, se actualiza el mismo elemento y sus criterios de aceptación se reemplazan por completo, así no quedan criterios antiguos.

Créalo en Azure DevOps → User settings → Personal access tokens, con el permiso Work Items: Read & write. Solo se envía a Azure DevOps.
